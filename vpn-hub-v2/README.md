# VPN Hub

Один сайт для VPN-ключей: вставляете ссылки и ключи, хаб проверяет их и
собирает **одну** ссылку-подписку для Happ. Если подключить Remnawave —
появляется раздел «Люди» и бот с пробным периодом.

Два модуля:

- **A. Источники и подписка** — работает всегда.
- **B. Люди** — включается только при заданном `REMNAWAVE_URL`. Без него
  раздел скрыт, а на его месте подсказка «Подключите панель».

## Что уже готово (этапы 1–3)

| Что | Где |
|---|---|
| Каркас, дизайн-токены, вход по паролю argon2 | `app/main.py`, `app/static/css/app.css` |
| Мастер первого запуска из трёх шагов | `app/templates/index.html` |
| Добавление нескольких строк за раз с проверкой каждого ключа | `app/services/sources.py`, `app/routers/pages.py` |
| Источники: статус, срок, трафик, удаление с подтверждением | главная страница |
| Сборка подписки `/sub/<токен>`, base64 + `subscription-userinfo` | `app/services/builder.py`, `app/routers/sub.py` |
| «Обновить всё» с живым логом (SSE) | `app/services/sync.py`, `app/services/bus.py` |
| Автообновление раз в 6 часов | `app/main.py` |
| Режим «белые списки» и ручной переключатель | `app/services/detector.py` |
| Уведомления в Telegram | `app/services/notifier.py` |
| **Бот на aiogram 3** (тот же токен, новый не нужен) | `app/bot/` |
| Тесты: парсер, приватность платных ключей, права админа | `tests/` |

Осталось: раздел «Люди» на сайте (тарифы, рассылки, журнал) — этап 5.
Он включается только при заданном `REMNAWAVE_URL`.

## Бот

Работает на **уже существующем** боте: впишите его токен в `BOT_TOKEN`.
Новый создавать не нужно.

```bash
docker compose up -d --build          # поднимет app, bot и caddy
docker compose logs -f bot            # видно «Бот @имя запущен»
```

Без Docker: `python -m app.bot.main`. Проверка конфигурации без сети:

```bash
python -m app.bot.main --check
# токен: есть
# админ: 5680608085
# обработчиков: 19
```

Команды и кнопки:

| Что | Как |
|---|---|
Меню | `/start` — кнопки «Моя ссылка», «Как подключить», «Состояние», «Обновить всё», «Помощь» |
Ссылка для Happ | `/link` или кнопка «Моя ссылка» |
Инструкция по устройству | кнопка «Как подключить» → Android / iPhone / Windows / macOS / Linux, в конце `happ://add/…` |
Состояние | `/status` — живые и мёртвые источники, ключи, режим |
Обновить всё | `/refresh` — запускает проверку, итог придёт в чат |
Добавить ключ | `/addkey`, затем одним сообщением ключ или ссылку (можно несколько строк) |
Режим сети | `/mode` — показать, `/mode whitelist` и `/mode normal` — переключить |
Проверка сети | `/probe` — российский и зарубежный сайт |
Список источников | `/report` |

Команды меняют состояние только у админа (`ADMIN_TG_ID`). Остальным бот
отвечает на общие кнопки, но не даёт управлять хабом. Есть лимит: 12 команд
в минуту с одного аккаунта.

Тексты инструкций лежат в базе (`settings.instruction.<устройство>`) и
переопределяют стандартные из `app/bot/texts.py` — их можно править без
перезапуска, когда появится раздел настроек.

**Если бот молчит**: сеть блокирует `api.telegram.org`. Укажите прокси:

```
TELEGRAM_PROXY=http://user:password@host:port
```

и перезапустите контейнер. Проверить связь: `docker compose logs -f bot` —
при старте бот пишет своё имя и отправляет админу «бот на связи».

## Быстрый запуск

```bash
git clone <репозиторий> && cd vpn-hub-v2
cp .env.example .env

# 1. секреты
python3 -c "import secrets;print('SECRET_KEY='+secrets.token_urlsafe(48))" >> .env
python3 -c "import secrets;print('SUB_TOKEN='+secrets.token_urlsafe(24))" >> .env
# 2. пароль админа (хеш)
docker compose run --rm app python -m app.cli hash-password 'мойПароль'
# вставьте вывод в ADMIN_PASSWORD_HASH в .env
# 3. адрес, по которому открывается сайт
# APP_URL=https://hub.example.com

docker compose up -d --build
```

Откройте `http://localhost:8080` — попадёте на вход, логин `admin`.

Без Docker:

```bash
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --port 8080
```

## Первый запуск: три шага

1. **Вставьте ссылку или ключ.** Скопируйте ссылку подписки в кабинете вашего
   VPN-бота или возьмите один ключ `vless://…`. Можно несколько строк сразу —
   тип определится сам (ссылка → публичная подписка, ключ → триал).
2. **Смотрите результат.** По каждой строке видно: сколько ключей нашлось,
   сколько живых, задержка и причина ошибки, если не отвечает.
3. **Копируйте ссылку.** Кнопка «Копировать ссылку», рядом «Открыть в Happ».

После добавления мастер сменяется обычной главной: поле вставки, список
источников, «Обновить всё» и ссылка для Happ.

## Happ

1. Установите Happ (Android, iOS, Windows, macOS).
2. «+» → «Импорт по ссылке» → вставьте ссылку из хаба → сохраните.
3. Выберите сервер и включите VPN.

Обновление подписки — автоматически, раз в 6 часов
(заголовок `profile-update-interval`). Вручную — потянуть список вниз.

## Как проверить, что всё работает

```bash
curl -s http://localhost:8080/healthz
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8080/login     # 200
curl -sD - -o /dev/null http://localhost:8080/sub/<SUB_TOKEN> | grep -i subscription-userinfo
curl -s http://localhost:8080/sub/<SUB_TOKEN> | base64 -d | head -3
```

В браузере: добавьте ключ → появится строка источника со статусом → нажмите
«Обновить всё» → в логе появятся шаги, внизу — тост «Обновление готово».

Тесты:

```bash
python -m pytest tests -q      # 16 passed
```

## Модуль B: подключить позже

1. Поднимите Remnawave и создайте API-токен.
2. В `.env`:
   ```
   REMNAWAVE_URL=https://panel.example.com
   REMNAWAVE_TOKEN=...
   BOT_TOKEN=токен_из_@BotFather
   ADMIN_TG_ID=ваш_telegram_id
   ```
3. `docker compose up -d --build` — появится раздел «Люди» и контейнер бота.

Пока переменных нет, ничего не ломается: раздел скрыт, бот не запускается.

## Типичные ошибки

| Что видно | Причина | Что сделать |
|---|---|---|
| «Неверный логин или пароль» | не задан `ADMIN_PASSWORD_HASH` | сгенерируйте хеш командой `hash-password` и впишите в `.env` |
| «Слишком много попыток» | 6 неудачных входов за 10 минут | подождите 10 минут |
| Источник сразу «Мёртвый» | ключ не отвечает или порт закрыт | проверьте ключ в клиенте, попробуйте другой |
| В подписке пусто | нет живых ключей | «Обновить всё», посмотрите лог и ошибки в строках |
| `subscription-userinfo` нет | подписка пустая | это нормально, пока нет живых ключей |
| Ссылка `/sub/...` отдаёт 404 | не совпал `SUB_TOKEN` | сверьте значение в `.env` и в ссылке |
| Страница без стилей | нет доступа к `/static` | проверьте прокси (Caddy) и `APP_URL` |

Логи: `docker compose logs -f app`.

## Безопасность

- Пароль — argon2, опционально TOTP (`TOTP_SECRET`).
- Cookie сессии: `HttpOnly`, `SameSite=Lax`, `Secure` при `APP_URL` с https.
- CSRF-токен на каждое изменение, лимит попыток входа.
- Секреты только в `.env`; в репозиторий он не попадает.
- Ссылки в интерфейсе маскируются, полностью — по клику.
- Источники «платный личный» и всё с `visibility=private` не попадают в
  подписку никогда — это закреплено тестом `tests/test_privacy.py`.
- Один User-Agent и один HWID на источник: сервисы не считают это новыми
  устройствами.

## Этапы и команды проверки

| Этап | Проверка |
|---|---|
| 1. Каркас, дизайн, вход | `curl -s localhost:8080/healthz` и вход в браузере |
| 2. Источники и `/sub` | добавить ключ, затем `curl -s localhost:8080/sub/<токен> \| base64 -d` |
| 3. Сроки, уведомления, режим | «Обновить всё» → лог; кнопка «Проверить сеть» |
| 4. Бот и Remnawave | `docker compose logs -f bot`, `/start` в боте |
| 5. Раздел «Люди» | таблица людей, карточка, тарифы |
| 6. Тесты и полировка | `python -m pytest tests -q` |

## Что нового в интерфейсе

- **Предпросмотр ключей**: кнопка «Проверить без сохранения» разбирает строки и
  показывает, что нашлось, ничего не записывая в базу.
- **Ручная выдача**: в карточке человека — дни, гигабайты и число устройств
  вводятся вручную одним действием, без тарифов.
- **Раздел «Люди»** (при подключённой панели): список с поиском и фильтрами
  (срок на исходе, трафик на исходе, триалы, платные), массовые действия,
  карточка с устройствами, заметкой и журналом.
- **Тарифы, рассылки, журнал аудита, настройки инструкций** — отдельные
  страницы в боковом меню.
- **Бот в стиле «пульта»**: «⚡️ Включить VPN» → выбор устройства, «👤 Кабинет»,
  «💳 Тарифы», «📊 Состояние», «🔄 Обновить всё», «❓ Помощь».
  Название задаётся переменной `BOT_NAME` (по умолчанию `Apelsinka VPN`).
