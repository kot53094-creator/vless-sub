# Установка Remnawave на AWS

Аккаунт AWS создаётся только вами: нужна карта, телефон и подтверждение. Дальше
всё делаю я по SSH.

## 1. Аккаунт

1. https://aws.amazon.com/free → Create account.
2. Регион выберите ближе к вам: `eu-central-1` (Франкфурт) или `ap-northeast-1`.
3. Нужна карта Visa/Mastercard (спишут ~$1 и вернут — это проверка).

## 2. Инстанс

EC2 → Launch instance:

| Параметр | Значение |
|---|---|
| Name | `remnawave` |
| AMI | Ubuntu Server 24.04 LTS |
| Instance type | **t3.small** (2 ГБ) — рекомендуется. t3.micro (1 ГБ) тоже пойдёт: установщик сам добавит swap |
| Key pair | создать новую, сохранить `.pem` |
| Storage | 20 ГБ gp3 |
| Security group | SSH (22), HTTP (80), HTTPS (443) — откуда угодно |

После запуска: скопируйте **Public IPv4 address** и путь к `.pem`.

## 3. Домен

Домен не обязателен. Вместо него используйте бесплатный nip.io — он
превращает IP в домен и на него выдаётся нормальный HTTPS-сертификат:

```
panel.203.0.113.10.nip.io
```

Ничего регистрировать не нужно. Просто подставьте свой IP.

## 4. Что пришлите мне

- IP сервера
- путь к `.pem` файлу (или положите его в `C:\Users\kryss\Downloads\`)
- имя пользователя: для Ubuntu AMI это `ubuntu`

Дальше я:

```bash
ssh -i key.pem ubuntu@IP
sudo bash /root/install.sh panel.IP.nip.io
```

и на выходе отдам ссылку на панель, логин-пароль администратора и привяжу её к
боту (`REMNAWAVE_URL`, `REMNAWAVE_TOKEN` в секретах Worker).

## Ограничения free tier

- 750 часов t3.micro в месяц бесплатно. **t3.small бесплатным не будет** —
  примерно $15/мес. Для панели с 1 ГБ придётся жить на swap: работать будет,
  но импорт больших списков и панель будут подтормаживать.
- Публичный IPv4 сейчас платный (~$3.6/мес), это не входит в free tier.
- Через 12 месяцев free tier заканчивается, цена станет обычной.
