# Совместимость с INCY

Проверено по официальной документации для разработчиков и репозиторию
приложения (ноябрь 2026):

- <https://docs.incy.cc/subscription-format/> — форматы подписок и заголовки
- <https://docs.incy.cc/full-xray-config/> — полные конфиги с балансировщиками
- <https://docs.incy.cc/routing/> — профили маршрутизации
- <https://github.com/INCY-DEV/incy-platforms> — протоколы и возможности

INCY — клиент на Xray-core. Он не предоставляет серверы и не меняет своё
поведение от того, что написано в подписке. Подписка может передать только
конфигурацию, заголовки карточки и профиль маршрутизации.

## Что поддерживает

| Возможность | Поддержка | Как используется у нас |
|---|---|---|
| `vless://` (в т. ч. REALITY) | да | основной формат |
| VMess, Trojan, Shadowsocks, Hysteria2, SOCKS5, HTTP, WireGuard, AmneziaWG | да | если источник отдаёт такие узлы |
| base64-список ссылок | да | `/sub/<токен>` |
| открытый список ссылок | да | `/list` |
| JSON: массив полных Xray-конфигов | да | `/sub/<токен>/groups` |
| `routing.balancers` + `observatory` | да, конфиг передаётся в Xray почти без изменений | профиль AUTO |
| профиль маршрутизации (proxy/direct/block, DNS) | да | заголовок `routing` |
| `subscription-userinfo` | да | трафик и срок в карточке |
| `profile-title`, `profile-description`, `support-url`, `profile-web-page-url` | да | карточка подписки |
| `hide-url` | да | скрыть ссылку из Share/QR |
| `sort-order` | `ping`, `name`, `none` | сортировка списка |
| `profile-update-interval` | да, часы | автообновление раз в час |

Не поддерживаются (распознаются, но не парсятся): `ssr://`, `tuic://`,
`hysteria://` (первая версия). AmneziaWG в теле подписки работает на iOS и
Android; desktop-клиент обрабатывает его как обычный WireGuard.

## Режимы: NORMAL, AUTO, SPLIT

Режим — это состояние клиента. Подписка не может «включить режим», она
может только выдать конфигурацию, которая соответствует режиму.

| Режим | Что делает инфраструктура | Что делает пользователь |
|---|---|---|
| **NORMAL** | отдаёт обычный список ссылок `/sub/<токен>` | выбирает сервер в списке вручную |
| **AUTO** | отдаёт профиль с балансировщиком `leastPing` и observatory (`/groups`, `/auto`) | выбирает в списке строку `AUTO · Апельсинка`; переключение делает Xray внутри клиента |
| **SPLIT** | отдаёт профиль маршрутизации (proxy/direct/block + DNS) заголовком `routing` | включает профиль; правила применяет клиент |

Никакого серверного «переключения на резервный сервер» не существует:
сервер не управляет уже установленным туннелем. Переключение возможно
только внутри клиента — балансировщиком (AUTO) или вручную. Это ограничение
протокола, а не недоделка.

## Как подключить

1. Откройте бота и получите ссылку `https://<воркер>/sub/<токен>`.
2. INCY → «+» → импорт из буфера обмена.
3. Разрешите добавление VPN-конфигурации.
4. Выберите сервер:
   - обычный список — `/sub/<токен>`;
   - группы с автоподбором — `/sub/<токен>/groups`;
   - только Европа — `/sub/<токен>/europe` (можно добавить отдельной
     подпиской, тогда в списке будет отдельная карточка).
5. Обновление — автоматически (`profile-update-interval: 1`), вручную —
   потянуть список вниз.

## Чего подписка не делает

- **Не меняет интерфейс INCY.** Тёмно-зелёная тема с лаймовыми акцентами,
  большой круглый индикатор, таймер и нижняя навигация — это оформление
  самого приложения. Подписка на него не влияет. Собственный интерфейс —
  отдельный продукт (своё приложение), а не настройка подписки.
- **Не показывает скорость соединения.** Скорость измеряет клиент или
  спидтест. В подписи узла может быть замер агента (Мбит/с), но это не
  скорость вашего канала.
- **Не гарантирует обход блокировок.** Проверка отвечает только на вопрос
  «трафик через этот конфиг проходит или нет» из сети проверяющего.
- **Не переключает серверы на стороне сервера.** Только клиентский
  балансировщик или ручной выбор.

## Заголовки, которые отдаёт воркер

| Заголовок | Значение |
|---|---|
| `profile-title` | `⚡ APELSINKA PREMIUM` (или имя группы) |
| `profile-update-interval` | `1` |
| `subscription-userinfo` | трафик и срок из базы либо тариф по умолчанию |
| `support-url` | бот поддержки |
| `profile-web-page-url` | адрес сервиса |
| `routing` | ссылка на профиль маршрутизации |
| `cache-control` | `no-store` |

## Если серверы не появились

| Симптом | Причина | Что делать |
|---|---|---|
| Пустой список | источник отдал заглушку `App not supported` | проверить `MERGE_HWID` и `FETCH_UA`, см. `MERGE.md` |
| Список есть, подключения нет | узел мёртв или заблокирован у оператора | обновить подписку, выбрать другой узел, проверить `/status` |
| Профиль AUTO не появился | клиент не поддерживает JSON-подписку | использовать `/sub/<токен>/all` |
| Показывает «0 Б / 0 Б» | в базе нет лимита и срока и отключена подстановка | включить `PREMIUM_LOOK=1` |
