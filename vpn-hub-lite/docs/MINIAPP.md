# Telegram Mini App — Личный кабинет «Апельсинка VPN»

Полноценный коммерческий личный кабинет VPN-сервиса в формате Telegram Mini App,
интегрированный в бота «Апельсинка VPN».

Дизайн выполнен в стиле Song69: глубокий графитово-синий фон (`#090D16`),
фирменный апельсиновый градиент (`#FF7A00`) и лаймовые акценты (`#70E000`),
стеклянные карточки (glassmorphism), скругленные углы и плавная навигация.

---

## 1. Разделы Mini App (5 вкладок без перезагрузки)

### 1. Главная (`Home`)
- **Шапка:** Логотип 🍊, статус подписки, быстрые кнопки (🎁 Бонус дня, 🔗 Ссылка).
- **Большая карточка подписки (Song69 Style):**
  - Название тарифа (`⚡️ APELSINKA PREMIUM` / `FREE`), бейдж статуса (`АКТИВНА` / `ИСТЕКЛА`).
  - Полоса использования трафика (Безлимит или реальный расход в ГБ).
  - Счётчик оставшихся дней и дата окончания.
  - Кнопка **«📋 Скопировать ссылку подписки»** с тактильным откликом.
  - Кнопка **«⚡️ Открыть в INCY»** для импорта в 1 клик.
  - Кнопка **«💳 Продлить»**.
- **Подключённые устройства:**
  - Карточка со списком активных устройств (например, `1 из 3 устройств`), название и время последней активности.
- **Группы серверов:**
  - Информационный блок о доступных группах: `AUTO (leastPing)`, `EUROPE`, `RUSSIA`, `BACKUP`.

### 2. Подписка (`Plans`)
- Текущий тариф и остаток дней.
- Сетка тарифов из базы данных (`1 месяц` — 190₽, `3 месяца` — 490₽ со скидкой 15%, `6 месяцев` — 890₽ со скидкой 25%, `1 год` — 1490₽ с выгодой 35%).
- Кнопка быстрой оплаты через бота.

### 3. Баланс (`Balance`)
- Отображение текущего баланса в рублях.
- Форма мгновенной активации промокода.
- История начислений и продлений.

### 4. Рефералы (`Referrals`)
- Персональная реферальная ссылка пользователя `https://t.me/<bot>?start=ref_<tg_id>`.
- Кнопка **«🚀 Поделиться ссылкой в Telegram»** (открывает окно пересылки другу).
- Счётчики: «Приглашено друзей» и «Бонусов получено».

### 5. Помощь (`Support`)
- Интерактивный FAQ-аккордеон (как подключить INCY, группы, устройства, смена серверов).
- Кнопка прямого перехода в поддержку.

## 2. Безопасность и аутентификация

- **HMAC-SHA256 валидация `initData`:** сервер проверяет хэш по алгоритму Telegram Web Apps с использованием `BOT_TOKEN`.
- **Защита от подмены:** `user.id` не принимается на веру от клиента, а извлекается только из проверенного `initData`.
- **Автоматическая регистрация:** если пользователь впервые открыл Mini App, он автоматически связывается с существующей записью в БД или создаётся новый активный аккаунт.
- **Резервная авторизация:** поддержка `x-sub-token` / `?token=` для тестирования вне Telegram.

## 3. Эндпоинты API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/app` | Страница Telegram Mini App (HTML/CSS/JS) |
| `GET` | `/api/app/me` | Состояние профиля, подписки, трафика, устройств, рефералов |
| `GET` | `/api/app/plans` | Список доступных тарифов для продления |
| `GET` | `/api/app/faq` | Вопросы и ответы, инструкции |
| `POST` | `/api/app/promo/claim` | Активация промокода |
| `POST` | `/api/app/daily/claim` | Получение ежедневного бонуса |
| `POST` | `/api/app/devices/toggle` | Блокировка/разблокировка устройства |
| `POST` | `/api/app/devices/delete` | Удаление устройства |
| `POST` | `/api/app/key/refresh` | Перевыпуск токена подписки |
| `GET` | `/api/app/history` | История начислений |

## 4. Как настроить кнопку в BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/mybots` -> выберите вашего бота.
3. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Отправьте URL: `https://<ваш_домен_или_воркер>/app`
5. Введите текст кнопки: `🍊 Кабинет`

Теперь у всех пользователей в левом нижнем углу чата будет постоянная кнопка для открытия личного кабинета!
