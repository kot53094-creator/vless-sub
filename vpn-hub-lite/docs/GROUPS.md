# Группы серверов: AUTO / EUROPE / RUSSIA / BACKUP / ALL

Группа — это правило отбора, а не надпись в списке. Клиент не умеет
переключать режим по команде подписки, поэтому каждая группа отдаётся либо
отдельной ссылкой, либо отдельным профилем в JSON-подписке. Никаких
переключателей-обманок: пустая группа не отдаётся вовсе.

## Что означают группы

| Группа | Кто попадает | Зачем |
|---|---|---|
| **AUTO** | до 12 проверенных узлов с наименьшей задержкой | балансировщик `leastPing` сам уводит поток на живой узел |
| **EUROPE** | страны Европы по ISO-коду (RU исключена) | привычный выход в ЕС |
| **RUSSIA** | только `RU` | российские адреса |
| **BACKUP** | проверенные узлы, не вошедшие в AUTO | второй эшелон, когда основной отбор просел |
| **ALL** | все узлы, кроме мёртвых, до 40 строк | длинный список для ручного выбора |

Мёртвые (`status=dead`) и исключённые администратором узлы не попадают ни в
одну группу. Узлы со статусом «не проверен» попадают в BACKUP/ALL и только
тогда, когда проверенных нет вообще — иначе AUTO обещал бы работу, которой
никто не подтвердил.

## Ссылки

Одна ссылка выдаёт все группы сразу:

```
https://<воркер>/sub/<токен>/groups
```

Ответ — JSON-массив полных конфигов Xray. В INCY, Happ и других клиентах с
поддержкой полного конфига это выглядит как пять записей в списке серверов:
`AUTO · Апельсинка`, `EUROPE · Апельсинка`, `RUSSIA · Апельсинка`,
`BACKUP · Апельсинка`, `ALL · Апельсинка`. Внутри каждой — свой
балансировщик и своя observatory: клиент сам замеряет узлы и переключается
без участия человека.

Отдельные списки (base64, для клиентов без поддержки JSON):

| Ссылка | Содержимое |
|---|---|
| `/sub/<токен>/europe` (или `/eu`) | только Европа |
| `/sub/<токен>/russia` (или `/ru`) | только Россия |
| `/sub/<токен>/backup` | резерв |
| `/sub/<токен>/all` | все узлы |

Основная ссылка `/sub/<токен>` не меняется: новые узлы появляются в ней
автоматически после синхронизации, перевыпускать ссылку не нужно.

## Как определяется страна

Страна берётся из гео-справочника по IP узла (`ipwho.is`, при отказе —
`ip-api.com`), а не из названия сервера. Тег «Германия» у источника может
стоять на нидерландском адресе; группа EUROPE должна отражать реальный
адрес, иначе она бесполезна.

Результат кэшируется в KV на 30 дней (`merge:geo:<host>`). За один прогон
делается не больше 12 новых запросов — бережём подзапросы воркера. Пока
страна не определена, узел остаётся в AUTO/BACKUP/ALL, но не в EUROPE и не
в RUSSIA.

Спорные гео (Казахстан, Грузия, Армения, Азербайджан, Турция) намеренно не
отнесены к Европе: они попадают в AUTO/BACKUP/ALL. Так честнее, чем
записывать Казахстан в европейскую группу.

## Безопасный период при исчезновении узла

Источник может ответить неполным списком: сработал лимит устройств, панель
перезагрузилась, ответ обрезался. Удалять узлы в этот момент нельзя.

Правило:

1. Источник ответил, узла в ответе нет → узел получает флаг `missing` и
   остаётся в подписке.
2. Узел держится `MERGE_GRACE_HOURS` (по умолчанию 24 ч) с момента
   последнего появления в источнике (`lastSeenAt`).
3. По истечении срока узел удаляется.

Если источник вообще недоступен (таймаут, HTTP 5xx, заглушка), его узлы
остаются без ограничения срока — это последняя рабочая версия.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `GROUP_AUTO_TOP` | `12` | сколько узлов в AUTO |
| `GROUP_LIMIT` | `40` | потолок узлов на группу |
| `MERGE_GRACE_HOURS` | `24` | безопасный период после исчезновения |
| `MERGE_ENABLED` | `1` | `0` — не подмешивать внешние узлы |

## Админка

`/admin/merge` показывает:

- счётчики по группам;
- сколько узлов помечено «нет в источнике» и сколько исключено;
- для каждого узла — в какие группы он входит;
- кнопку «Исключить»/«Вернуть» (ручное исключение из подписки и групп);
- кнопку «Синхронизировать сейчас» и выключение источника.

## Ограничения

- Группы собираются из объединённого пула внешних подписок. Если пул пуст,
  `/groups` вернёт пустой массив, а отдельные группы — заглушку с причиной.
- Задержка в подписи узла — результат замера агента через туннель, а не
  пинг вашего оператора. Реальную скорость она не обещает.
- Автоматическое переключение работает внутри группы: это балансировщик
  клиента, а не серверный оркестратор. Сервер не может переключить
  устройство, которое уже установило соединение.
